# tarn-http2

HTTP/2 client connections (RFC 9113) with a complete HPACK decoder (RFC 7541)
for [Tarn](https://github.com/tarn-lng/tarn), in pure Tarn over `net.TcpStream`.

**h2c with prior knowledge only.** Use it on trusted networks (for example a
private gRPC backend). TLS HTTP/2 needs ALPN, which Tarn's `TlsStream` does not
expose yet.

```tarn
import "http2"

fn get(address &string) Result<void, http2.Error> {
    var c = try http2.connect(address, &http2.Options.new())
    headers := [4]http2.Header{http2.Header.new(&":method", &"GET"), http2.Header.new(&":scheme", &"http"),
        http2.Header.new(&":path", &"/"), http2.Header.new(&":authority", address)}
    try c.open(&headers, true)
    for {
        match try c.receive() {
            http2.Event.Headers(list, end) => { if end { return Ok(()) } }
            http2.Event.Data(bytes, end) => { if end { return Ok(()) } }
            http2.Event.Reset(code) => { return Ok(()) }
        }
    }
}
```

- `connect`, `open(headers, end_stream)`, `send(data, end_stream)`,
  `receive() -> Event` (`Headers`, `Data`, `Reset`), `reset(code)`, `flush`.
- One open stream at a time per connection; streams can follow each other on
  the same connection and share the HPACK dynamic table.
- Flow control in both directions: received DATA is credited back as it is
  delivered; sends honour connection/stream windows, `INITIAL_WINDOW_SIZE`
  changes and `MAX_FRAME_SIZE`. SETTINGS and PING are acknowledged, GOAWAY and
  RST_STREAM are reported, server push is disabled.
- Blocking or nonblocking: call `set_nonblocking(true)`, register
  `stream()` with `net.Poll`, and drive `receive`/`send`/`flush` on readiness.
  Partial frames and queued output survive WouldBlock. `send_limit` bounds the
  output queue (TooLarge is the backpressure signal).
- The encoder emits literal-without-indexing, non-Huffman fields (valid for
  every peer, no encoder state).

## Tests

- `tarn test`: RFC 7541 Appendix C.4 and C.6 vectors (Huffman, dynamic table,
  eviction), encoder round trips, malformed blocks.
- `tests/run.sh path/to/tarn`: integration against Go `net/http` unencrypted
  HTTP/2 — repeated header blocks, 3 MiB download and upload under flow
  control, RST_STREAM, nonblocking 1 MiB full-duplex echo with trailers.

`hpack_tables.tarn` is generated by `tools/gen_hpack_tables.py` from
`golang.org/x/net/http2/hpack`; it asserts the Huffman code is canonical.
